# 敌人迁移方案与验证记录

来源：oldnoob666/brave-legend，提交 5ca382c5949154b8d8abc788ce124e298e3ec282。

用户要求：分析敌人代码，修改并接入当前游戏，完成后解释。直接在当前干净工作区实现，方便打开原项目检查；不提交或推送。

选择：复用原野猪美术和动画，保留状态机思路，重写适合俯视角的移动与战斗。
整套照搬会依赖横版地面检测、旧 Player、事件 SO 和渲染管线；只复制追击代码又不能形成完整战斗。采用小规模适配，不引入这些依赖。

1. 先写真实 Unity 行为测试：伤害、无敌、死亡一次、二维追击、丢失目标、击退、子弹命中、障碍、接触伤害、死亡停止控制。
2. 实现 CharacterHealth、EnemyController、PlayerHealth，扩展 SimpleBullet 并由武器传入发射者。
3. 校验本机同仓库美术与 GitHub blob SHA 一致后复制，保留 GUID；通过 Unity Editor 生成预制体并接入 SampleScene。
4. Unity 2022.3.59f1c1 编译，执行 PlayMode 测试，再验证实际场景和动画依赖；记录结果并写中文解释。

默认参数：玩家和敌人 100 血，子弹 20 伤害，接触 10 伤害；全向检测半径 6，追击 3，巡逻 1.2，丢失延迟 2 秒。参数均可在 Inspector 修改。

边界：本次不实现绕障寻路、刷怪波次或新敌种。测试检查高速子弹、重复碰撞、目标死亡、无动画组件等情况。
