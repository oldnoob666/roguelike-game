# 野猪敌人迁移说明

源仓库：https://github.com/oldnoob666/brave-legend

分析版本：`5ca382c5949154b8d8abc788ce124e298e3ec282`。

## 原项目怎样组织敌人

| 原脚本 | 职责 | 本次处理 |
| --- | --- | --- |
| enemy.cs | 通用移动、寻敌、状态切换、受伤与死亡表现 | 适配为 EnemyController.cs |
| Boar.cs | 创建野猪使用的状态对象 | 当前只有一种敌人，合并到控制器 |
| BaseState.cs | 规定进入、更新、物理更新、退出四个阶段 | 保留状态概念，以 enum 和少量方法表达 |
| BoarPatrolstate.cs | 左右巡逻、撞墙或遇到悬崖时等待转身 | 改为出生点附近的二维随机巡逻 |
| BoarChaseState.cs | 加速移动，丢失玩家后退出追击 | 改为朝玩家最后被发现的位置移动 |
| BoarDropState.cs | 受伤后等待恢复、落地 | 改为 Hurt 状态，等待 0.3 秒恢复 |
| PhysicsCheck.cs | 检测脚底地面和左右墙壁 | 当前俯视角不需要落地检测，不迁入 |
| character.cs | 扣血、受伤无敌、死亡与血量事件 | 适配为 CharacterHealth.cs |
| Attack.cs | 在触发器接触中提交伤害 | 分别交给子弹和敌人接触判定 |

原项目的 Drop 并不是掉落物品。其代码是在等待受击结束和落地。

没有整套复制旧 Player、场景事件 SO、UI 或旧预制体。当前游戏已有移动和射击系统，直接复制会引入额外依赖。

## 实际文件怎么分工

### Assets/Code/Enemy/EnemyController.cs

管理四种状态：

```text
Patrol：巡逻 → 发现玩家 → Chase
Chase：追击 → 超过 2 秒未发现玩家 → Patrol
存活状态：受到有效伤害 → Hurt → 根据是否仍能发现玩家决定 Chase / Patrol
任何存活状态：血量归零 → Dead
```

`enum` 是枚举，给这四种情况取名字，避免用难记的数字表示状态。

`Update()` 每个画面帧进行寻敌、计时和状态判断；`FixedUpdate()` 按物理步长设置移动速度。受伤和死亡时，普通移动逻辑停止，避免马上覆盖击退速度。

**寻敌**从原来的朝前方 BoxCast，改为计算玩家和敌人的距离。默认半径为 6，可以发现上下左右的玩家。它目前不检查视线遮挡。

**移动**使用目标位置减去敌人位置：

```csharp
Vector2 offset = destination - body.position;
body.velocity = offset.normalized * speed;
```

- `Vector2` 保存二维坐标或方向，包含 `x` 和 `y`。
- `offset` 同时包含“朝哪边”和“离多远”。
- `normalized` 返回长度为 1 的方向向量，让斜着移动也保持相同速度。
- `Rigidbody2D.velocity` 是每秒速度，赋值时不再乘 `Time.deltaTime`。
- 敌人重力设为 0，冻结旋转，适应俯视角。

**巡逻**从出生点周围随机选择目标，等待后走过去。`Random.insideUnitCircle` 返回单位圆内的随机点，乘巡逻半径后就得到可巡逻范围。

**丢失目标**后继续走向最后发现玩家的位置，2 秒后恢复巡逻；玩家死亡时立即停止追击。

**受伤**沿子弹飞行方向击退。朝向通过 `SpriteRenderer.flipX` 翻转贴图，不用改变整个对象的缩放，避免碰撞体被一起翻转。

**死亡**先停止移动、关闭碰撞体，再播放动画；动画事件或最多 0.5 秒的备用计时负责销毁。保留 `DestoryAfterAnim()` 这个旧拼写，是因为原死亡动画中的事件已经使用这个名字。

### Assets/Code/Combat/CharacterHealth.cs

玩家和敌人共用，负责血量和受伤后的无敌时间。

```csharp
public bool TakeDamage(int damage, Vector2 hitDirection,
    bool ignoreInvulnerability = false)
```

参数和返回值：

- `int damage`：整数伤害值，0 或负数会被忽略。
- `Vector2 hitDirection`：攻击指向受击者的方向，用于击退。
- `bool ignoreInvulnerability`：是否绕过无敌时间，默认 false；普通子弹和接触伤害使用默认值。
- 返回 `true`：本次成功扣血；返回 `false`：已死亡、伤害无效或仍在无敌时间内。

`CurrentHealth` 是当前血量，`MaxHealth` 是最大血量，`IsDead` 表示血量是否已归零。外部只能读取当前血量，统一通过 TakeDamage 修改，避免其他代码漏掉死亡和无敌判断。

非致命伤害发出 `Damaged` 通知，致命伤害发出 `Died` 通知。`event` 是事件：血量组件发通知，敌人或玩家组件决定如何反应。

`OnEnable` 用 `+=` 订阅事件，`OnDisable` 用 `-=` 取消订阅，避免禁用对象后仍然接收通知。

### Assets/Code/Combat/PlayerHealth.cs

收到死亡通知后，禁用 Player 移动与 SimplePlayerShooting 射击，并清空刚体速度。画面左上角显示血量，死亡后按 R 重载当前场景。

这是便于测试战斗的小型界面，后续有正式 UI 时可以替换 OnGUI，不影响血量与敌人逻辑。

### Assets/Code/SimpleShooting/SimpleBullet.cs

保留原来的飞行方向、速度和寿命，新增命中伤害。

```text
武器生成子弹
    → Initialize 接收方向和发射者
    → 扫描本帧将经过的路径
    → 命中敌人：调用 TakeDamage，然后销毁子弹
    → 命中实体障碍：销毁子弹
    → 到达寿命：销毁子弹
```

`Physics2D.CircleCastAll` 返回沿一段路径扫过的碰撞信息数组。使用子弹碰撞体的实际半径，按距离检查命中，减少高速子弹跨过较薄敌人的情况。

`spent` 记录子弹是否已经消耗，避免扫掠检测和触发回调重复结算。命中无敌中的敌人也会消耗子弹。

### Assets/Code/SimpleShooting/SimpleWeaponController.cs

只在初始化子弹时增加发射者：

```csharp
bullet.Initialize(aimDirection, transform.root);
```

`transform.root` 是武器所在层级最上方的 Transform，当前场景中是玩家。子弹因此可以跳过玩家及其子物体的碰撞体。

原有鼠标输入、瞄准、射速和武器管理保持现有行为；保留了用户自己添加的注释。

## 美术、预制体与场景

野猪贴图、动画和控制器来自源仓库。复制前校验了本机源文件与该提交的 Git blob SHA 一致，保留 .meta 中的 GUID，确保动画帧仍能找到对应贴图。

美术位于 `Assets/Art/Enemies/Boar`。移除了控制器中没有连接到行为、并引用缺失动画的旧 blue 状态；idle / walk / run / hit / dead 保留。

`Assets/Prefab/Enemy_Boar.prefab` 配置好敌人逻辑、血量、刚体、触发碰撞体和动画控制器。`SampleScene` 中放置三只，并为玩家补上血量和碰撞体。

`Assets/Editor/EnemyIntegrationSetup.cs` 提供 `Tools > Enemies > Setup Sample Scene` 菜单，用于重新生成接入场景。普通使用不必点击；此菜单会重设三只示例野猪的位置和预制体配置。

`Assets/Roguelike.Runtime.asmdef` 把游戏代码编译为一个程序集，引用原本就在项目中的 Unity Input System。Editor 与测试各自使用单独的 asmdef，避免进入游戏构建；没有新增第三方包。

## 如何运行和调整

打开 SampleScene，点击 Play。沿用原先的移动绑定，移动鼠标瞄准，按住左键射击。左上角看玩家血量，死亡后按 R 重开。

| 参数 | 默认值 | 调整位置 |
| --- | --- | --- |
| 玩家最大血量 | 100 | Player 的 CharacterHealth |
| 玩家受伤无敌 | 0.5 秒 | Player 的 CharacterHealth |
| 野猪最大血量 | 100 | Enemy_Boar 预制体的 CharacterHealth |
| 野猪受伤无敌 | 0.12 秒 | Enemy_Boar 预制体的 CharacterHealth |
| 子弹伤害 | 20 | Bullet_Gold 预制体的 SimpleBullet |
| 接触伤害 / 间隔 | 10 / 1 秒 | EnemyController |
| 发现玩家半径 | 6 | EnemyController |
| 巡逻速度 / 半径 | 1.2 / 2 | EnemyController |
| 追击速度 | 3 | EnemyController |
| 丢失玩家等待 | 2 秒 | EnemyController |
| 受伤恢复 / 击退速度 | 0.3 秒 / 4 | EnemyController |

`[SerializeField]` 让 private 字段显示在 Inspector；`[Min]` 给 Inspector 输入设置下限；`[RequireComponent]` 在添加脚本时自动补上必要组件。

第一版敌人使用触发碰撞体，玩家与野猪能够互相穿过并结算接触伤害。目前场景没有实体墙；后续加入墙体时，需要增加实体碰撞与相应避障策略。本次没有实现绕墙寻路、刷怪波次或新敌种。
